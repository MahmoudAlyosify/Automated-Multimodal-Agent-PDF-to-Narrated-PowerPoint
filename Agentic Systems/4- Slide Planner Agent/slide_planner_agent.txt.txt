AGENT NAME: Slide Planner Agent

PURPOSE:
This agent performs high-level reasoning and planning.
It transforms retrieved knowledge into a structured presentation plan.
This is the primary "thinking" agent in the system.

INPUT:
- Retrieved semantic chunks
- Constraints:
  - Target slide count (5–10)
  - Educational lecture format

OUTPUT:
A slide blueprint defining intent and structure for each slide.

OUTPUT SCHEMA:
{
  "slide_id": 3,
  "title": "System Architecture",
  "intent": "Explain the overall workflow",
  "source_chunks": [4, 9, 12]
}

PLANNER PSEUDO-CODE:
1. Retrieve top-K relevant chunks from vector store.
2. Group chunks by conceptual similarity.
3. Decide slide boundaries based on topic cohesion.
4. Enforce one main idea per slide.
5. Order slides to maintain narrative flow.
6. Return slide blueprint.

PROMPT TEMPLATE (Mistral 7B):
You are a presentation planning agent.

Task:
- Design a lecture-style slide structure from the provided content.
- Generate between 5 and 10 slides.
- Each slide must represent one core idea.
- Do NOT generate slide text.
- Output a structured JSON plan only.

MODEL:
- Mistral 7B
